L'Essenza del Software

Orbita Casa è un ecosistema progettato per chi vuole il controllo totale sulle proprie finanze senza rinunciare alla Privacy. Unisce la potenza di un software gestionale alla semplicità di un'app domestica.

Se usi il Webserver fuori casa, consigliamo una VPN. Proteggi i tuoi dati da occhi indiscreti.

Scarica .zip

!

Rieseguendo l'installer potrai creare nuovi profili utente separati.

Procedura per codice sorgente:

  1. Crea una cartella dedicata — il nome sarà il tuo Nome Profilo.
  2. Inserisci il file OrbitaCasa.pyw all'interno.
Prerequisito Python: Durante l'installazione (v3.13+), spunta "Add Python to PATH".

Librerie (solo in caso di errori all'avvio):

pip install tkcalendar google-genai requests segno pypiwin32 cryptography pystray pymupdf flask tkinterdnd2 yfinance
